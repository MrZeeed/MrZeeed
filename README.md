## Featured project

### University Journey — UK University Application Tree

An interactive website that makes the UK university application process easier to explore, from application submission through offers, CAS and visa outcomes.

**4 stages · 37 statuses · 50 next-step connections**

| Stage | What it covers |
| --- | --- |
| Application & review | Submission, admissions review, pending documents, additional evidence and rejection |
| Offer & conditions | Conditional and unconditional offers, document requests, interviews, payments, cleared conditions and acceptance |
| CAS & university checks | CAS requests, pre-CAS checks, outstanding requirements, draft details, corrections and issuance |
| Visa initiation & outcome | Preparation, readiness checks, submission, identity steps, pending decisions, evidence requests and outcomes |

#### Features

- Expand individual branches or the complete status tree.
- Search statuses and follow connected next steps, including review loops.
- Mark the current status and add a separate note to each step.
- Use a responsive layout on desktop, tablet and mobile.
- Print the expanded workflow.
- Navigate with keyboard controls and visible focus indicators.

#### Built with

**HTML5 · CSS3 · JavaScript · Inline SVG**

The website runs without a framework, external fonts or third-party runtime dependencies. Node.js provides the optional local development server and workflow validation tools.
